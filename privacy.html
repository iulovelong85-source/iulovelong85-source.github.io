Privacy Policy — rclone-backup

Last updated: 2026-10-28

  • rclone-backup is used only by its owner to back up the owner's own files.
  • It requests the Google Drive drive.file scope, which allows access only to files the app itself creates.
  • No personal data is collected, sold, or shared with any third party.
  • Google user data is used only to upload and manage the owner's backup files, in line with the Google API Services User Data Policy, including the Limited Use requirements.
